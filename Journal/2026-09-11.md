# What Confused Me

I was confused about `=`, `==`, and `!=`. I learned that `=` assigns a value to a variable, `==` checks whether two values are equal, and `!=` checks whether two values are not equal.

I was confused about why `scanf` can be used inside `if ( )`. I thought the brackets in an `if` statement could only contain maths, not functions. I learned that maths calculates or checks values, while functions perform an action. Some functions, such as `scanf`, also return a value.

`scanf` takes input and stores it in a variable. It returns `1` when it successfully reads one integer and `0` when the input is invalid, such as letters.
```cpp
if (scanf("%d", &x) != 1)
```

This checks whether the user failed to enter a valid integer. If the input is invalid, the program displays an error message.

I was confused about `if if else`. I learned that separate `if` statements are checked independently, so the program can print more than one result. I should use `if / else if / else` when the program should choose only one result: positive, neutral, or negative.

I also learned that `return 0;` means the program completed successfully, while `return 1;` means the program stopped because of an error, such as invalid input.
