# What Confused Me

I was confused about why `else` was not needed after checking `scanf()`. I learned that when `return 1` is used inside the `if`, the program stops immediately if the input is invalid, so the code after the `if` can continue normally without an `else`.

I also learned that `float` can store both whole numbers and decimal numbers, while `int` is mainly used for whole numbers.

I was confused about `9 / 5` and `9.0 / 5.0`. I learned that `9 / 5` uses integer division and gives `1`, while `9.0 / 5.0` gives `1.8`.
