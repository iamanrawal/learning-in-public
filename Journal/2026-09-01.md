# What I Learned

Today I learned more about Git and GitHub, along with HTML, C, and Artificial Intelligence & Machine Learning.

- `Git` status checks the current state of the repository.
- `Git` add stages changes.
- `Git` commit saves a snapshot locally.
- `Git` push uploads changes to GitHub.
- `Branches` are separate lines of development.

# Git Workflow

`git status` → `Check changes`  
`git add` → `Stage changes`  
`git commit` → `Save a snapshot`  
`git push` → `Upload changes to GitHub`
