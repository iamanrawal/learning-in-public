\* git status checks the current state of the repository.

\* git add stages changes for the next commit.

\* git commit creates a snapshot of the staged changes locally.

\* git push uploads commits to GitHub.

\* A branch is a separate line of development used to work on changes without directly affecting the main branch.

\* The basic Git workflow is git status → git add → git commit → git push.
