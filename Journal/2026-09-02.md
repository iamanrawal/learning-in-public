# What Confused Me

I initially thought the difference was that `Supervised ML` uses data with patterns, while `Unsupervised ML` uses data without patterns.

I later learned that the actual difference is that `Supervised Learning` uses input data with correct answers or labels, while `Unsupervised Learning` uses input data without given answers or labels and tries to find patterns or structure on its own.
